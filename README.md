# Digital Menu

This is our website project for Bloom Room Cafe. We made a simple digital menu with information about the cafe and its food.

There are four pages in the project:

- Home
- Breakfast
- Lunch
- About

We used HTML, CSS and Bootstrap. The website has a responsive layout, so it can be opened on a computer, tablet or phone. Bootstrap is used for the navigation bar, grid, cards, buttons, carousel and form. We also used CSS media queries for the responsive card group and text sizes.

Open `index.html` in a browser. We recommend using Live Server in Visual Studio Code so the pages are easier to test.
